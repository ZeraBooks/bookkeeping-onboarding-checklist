# Changelog

- `check_statement_coverage.py`: `--request` drafts the message asking the client for what's missing; `--json`; flags statements received twice and statements outside the months needed; matches a differently named statement by its last 4; exit code 2 on bad input. The default output is unchanged.
- JSON Schemas for the inventory, the received list and the document request.
- Eight fictional onboardings in `samples/`, generated by `scripts/generate_samples.py`, each with `expected.json`.
- Tests, `MANIFEST.json`, `checksums.txt` and a release zip.
- CITATION.cff now points at this repository.
